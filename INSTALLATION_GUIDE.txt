# ForensiX Pro - Installation & Quick Start Guide

A professional-grade suite for recovering deleted files, analyzing event and browser logs, generating correlated timelines, collecting cryptographic evidence, and producing court-ready forensic reports.

---

## Quick Installation (One Click Setup)

### Recommended for Windows Users
1. Clone or extract the repository folder
2. Double-click **`one_click_setup.bat`**
3. The setup script will:
   - Verify Python 3.8+ installation
   - Install required libraries (`PyQt5`, `pandas`, `psutil`)
   - Launch the ForensiX Pro GUI (`launch_gui.py`)

---

## Manual Installation (Advanced Users)

1. Open PowerShell or Command Prompt in the repository folder:
   ```cmd
   pip install -r requirements.txt
   ```
2. Launch the application:
   ```cmd
   python launch_gui.py
   ```

## System Requirements
- Operating System: Windows 10 / Windows 11 (Windows 7+ supported)
- Python Version: Python 3.8 or higher
- Privileges: Administrator rights recommended for Windows Event Log extraction
- Memory: 2GB+ RAM
- Storage: 100MB+ free disk space

---

## Core Modules
- **FileRecoveryEngine**: Windows $I/$R binary Recycle Bin parser and file restoration
- **LogAnalyzer**: Windows Event Logs (.evtx) and Multi-Profile Browser History (Chrome, Edge, Firefox, Brave, Opera)
- **TimelineCreator**: Chronological event correlation with zero-drop date normalization
- **EvidenceCollector**: SHA-256 chain of custody tracking and ZIP/folder packaging
- **ReportGenerator**: Web-responsive HTML reports and structured RFC-4180 CSV exports

## Troubleshooting

### Administrator Privileges
- If Windows Event Logs (Security) cannot be accessed, right-click `launch_gui.bat` and select **"Run as administrator"**.

### Browser History Locked
- ForensiX Pro uses non-locking read-only shadow buffers, but for complete live cache flushing, closing browser instances before scanning is recommended.
